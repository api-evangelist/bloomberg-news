Users can monitor FX pricing by organizing scattered chat-based quotes into clear data detected by Bloomberg’s NLP Bloomberg today introduced MYQ, a price monitoring tool that displays FX quotes detected by Bloomberg’s NLP within a user’s Instant Bloomberg (IB) chats. The solution provides each user with insights into the FX liquidity available to them and improves price discovery through an overview of quotes from a user’s chats with counterparties.
